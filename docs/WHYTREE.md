# Why Tree — MyPitchPlaylist

## 트리 구조

아래에서 위로 올라가면 "왜?(Why Up)", 위에서 아래로 내려가면 "어떻게?(How Down)"

```
                        ┌──────────────────────────┐
                        │  일상에서의 즐거움과 자신감  │
                        └─────────┬────────────────┘
                                  │ 왜?
                     ┌────────────┴─────────────┐
                     │                          │
          ┌──────────┴──────────┐    ┌──────────┴──────────┐
          │ 노래 부르는 즐거움을  │    │  새로운 노래를 발견하는 │
          │ 느끼기               │    │  재미                 │
          └──────────┬──────────┘    └──────────┬──────────┘
                     │ 왜?                       │ 왜?
                     │                          │
          ┌──────────┴──────────┐    ┌──────────┴──────────┐
          │  내 목소리에 맞는     │    │  내 취향에 맞는 곡을   │
          │  노래를 편하게 부르기  │    │  쉽게 탐색하기        │
          └──────────┬──────────┘    └──────────┬──────────┘
                     │ 왜?                       │ 왜?
                     │                          │
          ┌──────────┴──────────┐    ┌──────────┴──────────┐
          │  내 음역대에 맞는     │    │  장르/연대별로 필터링된 │
          │  곡을 추천받기       │    │  결과를 받기           │
          └──────────┬──────────┘    └──────────┬──────────┘
                     │ 어떻게?                    │ 어떻게?
          ┌──────────┼──────────────┐            │
          │          │              │            │
   ┌──────┴───┐ ┌───┴────┐ ┌──────┴─────┐ ┌───┴──────────┐
   │ 음성 녹음 │ │ 피치    │ │ 유튜브 API │ │ 취향 선택     │
   │ 및 입력   │ │ 감지    │ │ 검색       │ │ (장르, 연대)  │
   └──────┬───┘ └───┬────┘ └──────┬─────┘ └──────────────┘
          │ 어떻게?  │ 어떻게?      │ 어떻게?
          │         │             │
   ┌──────┴───┐ ┌───┴──────┐ ┌───┴──────────┐
   │ 마이크    │ │ 음높이    │ │ 키워드 기반   │
   │ 입력 UI  │ │ 분석     │ │ 영상 검색 및  │
   │          │ │ 알고리즘  │ │ 플레이리스트  │
   │          │ │          │ │ 생성          │
   └──────────┘ └──────────┘ └──────────────┘
```

## 핵심 발견

- **"왜?"를 올라가다 보면** "노래 부르는 즐거움"과 "새로운 노래 발견의 재미"라는 두 가지 핵심 가치가 하나로 수렴한다: **일상에서의 즐거움과 자신감**.
- **"어떻게?"를 내려가다 보면** 음성 녹음, 피치 감지, 유튜브 API, 취향 필터링이라는 네 가지 구체적 수단이 드러난다.
- 피치 감지와 유튜브 API 검색은 "음역대 맞는 곡 추천"과 "취향 맞는 곡 탐색" 두 가지 목적(why)을 동시에 충족하는 수단(how)이다.
