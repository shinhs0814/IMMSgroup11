## Wedge의 3가지 차원 압축

원래 MANIFEST는 모든 차원을 동시에 풀려고 함. 1차원씩 좁힙니다.

| 차원 | MANIFEST의 야망 | Wedge의 선택 | 이유 |
|---|---|---|---|
| **언어** | 다국어 (한/영/일/중...) | **한국어만** | 가장 익숙한 언어로 시작. 데이터 수집/검증이 가능. |
| **식이 제한** | 비건 / 알레르기 / 종교 / 당뇨 / 의학 등 전부 | **비건만** | 1) 동물성 성분 목록은 finite + well-known. 2) 알레르기는 법적 책임이 너무 큼. 3) 종교/의학은 전문성 필요. |
| **음식 환경** | 가공식품 / 식당 메뉴 / 손글씨 메뉴판 / 길거리 음식 | **편의점 가공식품 라벨만** | 1) 라벨은 인쇄됨 (OCR 잘 됨). 2) 평평하고 조명이 일정. 3) GS25/CU/세븐일레븐 3개 체인이 시장 80% 점유. |

→ **3차원의 곱이 모두 1로 줄어듦. (1 lang × 1 diet × 1 setting)**

## 사용자 시나리오 (golden path)

> "Sarah, 한국 거주 인도인 비건 IT 매니저. 점심으로 GS25에서 컵라면을 사고 싶다."

1. Sarah는 GS25에서 진라면 봉지를 든다.
2. 앱(또는 웹)을 연다.
3. 봉지 뒷면 성분표를 카메라로 찍는다 (한국어).
4. 2초 안에 화면에 나타남:
   - **결과:** 🔴 비건 불가능
   - **이유:** "쇠고기 분말 (3번째 성분), 닭고기 향료 (5번째 성분) 검출"
   - **신뢰도:** 95%
5. Sarah는 진라면을 내려놓고 다른 라면을 든다. 다시 찍는다.
6. 🟡 의심 — "L-시스테인이 동물성/식물성 양쪽 가능. 제조사 직접 확인 권장."
7. 다른 제품 → 🟢 비건 가능.

**이 시나리오를 30초 안에 완료할 수 있어야 함.**

## 입력 / 처리 / 출력 명세

### 입력
- 1장의 사진 (스마트폰 카메라 또는 업로드)
- 성분표가 한국어로 인쇄되어 있어야 함
- 식이 기준: "비건"으로 고정 (V1은 선택 UI 없음)

### 처리 (3단계)
1. **OCR**: 사진 → 한국어 텍스트 (예: Tesseract / Google Vision API / Claude Vision)
2. **성분 파싱**: 텍스트 → 성분 리스트 (쉼표/소괄호 구분)
3. **비건 판정**: 각 성분을 "동물성 단어 사전"과 매칭
   - 명백한 동물성 (쇠고기, 돼지고기, 닭고기, 우유, 계란, 젤라틴, ...) → 🔴
   - 명백한 식물성 (대두, 밀가루, 소금, ...) → 🟢
   - 모호 (L-시스테인, 향료, 유화제 ...) → 🟡

### 출력
- **3-state 판정**: 🟢 가능 / 🟡 의심 / 🔴 불가능
- **이유**: 검출된 동물성 성분 리스트 (또는 모호 성분)
- **신뢰도**: % 표기 (OCR 정확도 + 사전 매칭 정확도)

## 성공 기준 (Success Criteria)

학기말까지 **다음 3가지 중 2개 이상**이 측정 가능해야 함:

1. **OCR 정확도**: 편의점 라벨 50장 테스트셋에서 텍스트 인식률 ≥ 80%
2. **판정 정확도**: 명백한 동물성 성분 (10종 키워드) 검출률 ≥ 95%
3. **체감 속도**: 사진 업로드 → 결과 표시 ≤ 5초 (모바일 4G 기준)

**bonus:** 비건 친구 3명 이상에게 시연했을 때 "이거 쓰겠다"는 반응 (유료가 아니어도 OK).

## 4명 팀 분담 가설 (제안 — 팀 미팅에서 합의 필요)

| 역할 | 담당 영역 | 예상 산출물 |
|---|---|---|
| 백엔드 1 | OCR 파이프라인 (이미지 → 텍스트) | API endpoint `/ocr` |
| 백엔드 2 | 성분 사전 + 판정 로직 (텍스트 → 3-state) | API endpoint `/classify` + `data/ingredients.json` |
| 프론트 | 카메라 UI + 결과 표시 | 모바일 친화 웹페이지 (Next.js / React Native 중 선택) |
| 데이터/QA | 편의점 50개 제품 테스트셋 + 정답 라벨링 | `data/test_set/` + 정확도 측정 스크립트 |

→ 각자 1주일씩 잡아도 학기 내 작동 가능.
